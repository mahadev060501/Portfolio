Routing Protocol

Multi-Area OSPF Enterprise Network

Built a multi-area OSPF topology connecting multiple branch offices to a central headquarters — focusing on efficient route propagation, minimized LSA flooding, and fast convergence.

Challenge
Connect geographically spread branch offices with scalable dynamic routing while keeping the backbone area stable and reducing unnecessary LSA flooding.
Outcome
All branches achieved full reachability. Route summarization at ABRs reduced LSA overhead, and OSPF neighbor relationships were fully verified using Cisco IOS show/debug commands.
OSPF Multi-Area Area 0 (Backbone) ABR Configuration Route Summarization Neighbor Verification Cisco IOS Debug

Hardened an enterprise network with layered access control and device security — restricting unauthorized traffic, securing management interfaces, and validating all policies end to end.
